Proteger seu backup

O arquivo é processado neste navegador. Esta página não envia o backup nem a senha para um servidor.

Use pelo menos 12 caracteres. Guarde a senha separadamente: não há recuperação se você esquecê-la.

Como usar com o aplicativo

  1. Exporte o backup pelo aplicativo e escolha esse arquivo acima.
  2. Guarde o arquivo protegido e sua senha em lugares separados.
  3. Para restaurar, abra o arquivo protegido aqui e importe o JSON recuperado no aplicativo.

O JSON recuperado volta a conter os dados legíveis. Remova cópias desprotegidas quando não forem mais necessárias. Esta ferramenta protege o arquivo exportado; os dados em uso no aplicativo continuam sujeitos à segurança do aparelho e da conta.
